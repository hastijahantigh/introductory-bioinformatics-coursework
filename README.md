# Introductory Bioinformatics Coursework

Coursework completed for the Introductory Bioinformatics course, Fall 2025.

**Students:** Hasti Jahantigh and Bahar Marashi

## Assignment 1

This assignment covers:

- FASTQ read inspection using Biopython

- Sequence-quality analysis with FastQC

- De novo genome assembly using SPAdes

- Assembly evaluation using QUAST

- Read mapping using BWA and Samtools

- Alignment visualization using IGV

- Comparison of different reference genomes

The sequencing dataset is available through accession SRR36584168.

The repository contains the final report, the Python analysis script, and the two plots generated by the script. Raw sequencing data and large intermediate files are not included.
