# Assignment 1

This assignment was completed for the Introductory Bioinformatics course in Fall 2025.

**Students:** Hasti Jahantigh and Bahar Marashi

## Overview

The assignment covers basic analysis of sequencing data, including:

- Inspecting FASTQ reads with Biopython
- Evaluating sequence quality with FastQC
- Performing de novo genome assembly with SPAdes
- Evaluating the assembly with QUAST
- Mapping reads to different reference genomes using BWA and Samtools
- Visualizing alignments with IGV
- Comparing mapping results across reference genomes

The sequencing dataset is publicly available under accession `SRR36584168`.
